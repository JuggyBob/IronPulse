# IronPulse 5.1.0 — portfolio screenshots

These are the final, full-resolution screenshots for the IronPulse 5.1.0 public release. They were
captured from the **5.1.0 (15)** build on AVD **`dh36`** (emulator) at **1080 × 2400**,
Android 16 / API 36.

Every image uses the mandatory appearance settings, verified in `09-appearance.png` before and
during the session:

1. **Theme: AMOLED Dark**
2. **Accent: IronPulse Blue**
3. **Liquid Glass: ON**
4. **Material Expressive 3: ON**

The data is a fictional demonstration athlete ("Alex Carter") — seven Routines, 22 logged workouts,
five weigh-ins, drop sets and an A1/A2 superset pair — created for documentation only. No real user
data, debug overlay, emulator chrome or test-only screen is present.

| File | Feature area | What it shows |
|---|---|---|
| `01-home-dashboard.png` | Home | Today's planned workout ("Lower Body & Core"), week stats, shortcuts and the streak heat map |
| `02-home-last-workout.png` | Home | Expanded Last Workout with Set N rows, A1/A2 paperclip badges, D1 drop rows and body weight |
| `03-plan-routines.png` | Plan | The Routines page: one card per reusable workout with Start/share/duplicate/edit/delete |
| `04-routine-superset-editor.png` | Plan | Editing a Routine: paperclip links, the highlighted superset pair, Target effort and drop-set panels |
| `05-active-workout-superset.png` | Workout | Active workout with the paired exercise chips and D1 drop-set branches under each main set |
| `06-history-filters.png` | Progress / History | Full-screen Workout History with search, date and exercise filters |
| `07-export-format-sheet.png` | Export | The Export routine sheet with full-width PDF / CSV / Excel format rows |
| `08-export-pdf.png` | Export | The PDF preview: two-column exercise cards, indented D1 drop sets and A1/A2 labels, with Export/Cancel |
| `09-appearance.png` | Appearance | **AMOLED Dark + IronPulse Blue + Liquid Glass ON + Material Expressive 3 ON** |
| `10-progress-analytics.png` | Progress | 12-month activity heat map, body-weight timeline and Weigh-in Logs |

The same files are referenced by the repository [README](../../../README.md); this directory is the
