# IronPulse 5.0.0 — portfolio screenshots

These are the final, full-resolution screenshots for the IronPulse 5.0.0 public release. They were
captured from the **release-signed 5.0.0 (13)** build on `emulator-5556` at **1080 × 2400**,
Android 16 / API 36.

Every image uses the three mandatory appearance settings, verified in
`23-appearance.png` before and during the session:

1. **Theme: AMOLED Dark**
2. **Liquid Glass: ON**
3. **Material Expressive 3: ON**

The data is a fictional demonstration athlete ("Alex Carter") with five Routines, a five-day
Schedule, nine weeks of training, ten weigh-ins, a 29-day streak, drop sets, warm-up sets and an AI
conversation. No real user data, debug overlay, emulator chrome or test-only screen is present.
